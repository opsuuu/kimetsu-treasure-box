# Kimetsu Treasure Box 🗡️🦋

A fan-made catalog website for **Kimetsu no Yaiba (Demon Slayer)** merchandise and collectibles.

Kimetsu Treasure Box is a personal project dedicated to documenting and organizing Demon Slayer merchandise, including figures, acrylic stands, keychains, and other collectibles.

This project started as a personal archive for my collection and may expand to include merchandise from various characters in the future.

---

## ✨ Features

- Browse Demon Slayer merchandise catalog
- View product details and images
- Search and filter merchandise
- Responsive UI design
- Progressive Web App (PWA) support

---

## 🛠 Tech Stack

- React
- Vite
- TypeScript
- React Router
- TailwindCSS / UI Library
- PWA (vite-plugin-pwa)
